# v23.7.6 — Verification client-side exception fix

## Root cause
Verification rendered `const humanDynamic=hasHuman;` in `Review`, but `hasHuman` was not defined. This caused a browser-side `ReferenceError` when opening Verification.

## Fix
Changed the value to `const humanDynamic=hasHumanROI;`, which is the existing boolean derived from the saved Human ROI fields.
