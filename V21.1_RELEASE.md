# UV-Tape Residue EDS — V21.1

## Fixes
- Fixed the Vercel production build error in `frontend/app/AppClient.js` caused by the compact JSX metric-bar expression.
- Verification desktop UI now uses the requested layout: SEM + Full EDS on the left, C/O ROI maps enlarged below, and a dedicated **Analysis Result** panel fixed on the right.
- N and Si are not shown in Verification.
- Full EDS panel now prefers a generated **C + O overlay** with the actual irregular ROI contour.
- New/Re-analysis outputs continue to omit the Local Ring; legacy stored overlays may still show it until Re-analysis.
- Score bands remain: **>=70 Residue / 60–69 Ambiguous / <60 Non-residue**.
- Score calibration remains piecewise on a true 0–100 scale: previous 85 maps to new 70 and previous 100 maps to new 100; no flat -15 offset.

## Compatibility
All existing dashboard, verification, gallery, re-analysis, R2/Supabase, upload and AI-review workflows are retained from V21.
