# UV-Tape Residue EDS v21.6

Patch release based on v21.5. Existing UI, project loading, Dashboard, Verification, Gallery, AI Analysis, Re-analyze, R2/Supabase/API/upload flows are preserved.

## v21.6 analysis changes

1. **Visual-first residue evidence**
   - SEM morphology remains the primary evidence.
   - C/O EDS are supporting evidence, not a replacement for visible SEM contrast.
   - Added SEM local contrast and eroded-interior evidence to the stored feature set.

2. **Shadow suppression**
   - Stronger local-background separation is used during candidate generation/refinement.
   - Candidate expansion is tighter so broad illumination/shadow halos are less likely to become part of the ROI.

3. **Edge-only artifact suppression**
   - The score now checks the interior of the ROI separately.
   - A thin edge/rim with little interior contrast is prevented from receiving a residue-like score merely because an EDS channel is locally strong.

4. **ROI behavior**
   - ROI remains an irregular pixel mask/contour, not a fixed rectangle.
   - Bottom SEM/EDS metadata and scale-bar region remain excluded from analysis.
   - Image border remains excluded.
   - Local Ring is not generated or used for the new score.

5. **Score**
   - Existing 0-100 display and 70/60 decision bands are preserved.
   - Added `sem_contrast`, `sem_contrast_score`, `sem_interior_score`, `visual_evidence`, and `element_support` diagnostics.
   - A high C/O signal alone can no longer compensate as strongly for weak SEM interior evidence.

## Important

This is a patch to the existing production structure, not a new standalone UI. Existing features are intentionally retained.
