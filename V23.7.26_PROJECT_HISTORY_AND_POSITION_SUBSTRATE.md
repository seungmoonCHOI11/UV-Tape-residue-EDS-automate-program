# v23.7.26 — Project History + Position Substrate Mapping

## Project history
- New PDF uploads always create a new UUID project and remain stored in Supabase/R2.
- Added `/api/projects` history endpoint.
- Frontend sidebar now includes a project selector so older datasets can be reopened after a new upload.
- Latest/selected project metadata is preserved and loaded without deleting previous projects.

## Position substrate mapping
- Added per-position substrate mapping for P1–P9.
- Allowed values: SiCN, Si, SiN, SiO2.
- Default: all positions = SiCN.
- Mapping is saved in project metadata and copied into each point's analysis features as `substrate_type`.
- Re-analysis reuses the saved position mapping.
- Existing CV/EDS classification and C/O ratio calculations are unchanged; substrate metadata is stored for correct experiment context and future substrate-specific baselines.

## Example
- P1 = SiCN
- P4 = SiCN
- P5 = SiCN
- P9 = Si
- P2/P3/P6/P7/P8 remain SiCN unless changed.
