# v23.7.19 — Human ROI Auto-Complete

- Rebased on v23.7.18.
- When the user releases the mouse after drawing a Human ROI, the current freehand stroke is automatically smoothed and saved as a completed ROI region.
- The user no longer needs to press `✓ 영역 완료` after every region.
- Removed `pointerleave` from the drawing canvas so merely moving outside the canvas does not accidentally finalize the ROI; pointer capture still handles the normal mouse-release flow.
- Existing Human ROI smoothing, red 4px stroke, multi-region support, Save Human ROI flow, and C/O calculation are preserved.
- The manual `✓ 영역 완료` button remains available for safety/compatibility, but normally is not needed.
