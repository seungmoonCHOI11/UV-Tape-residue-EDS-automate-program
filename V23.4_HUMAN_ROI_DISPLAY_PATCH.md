# V23.4 Human ROI Display Patch

- After Human ROI save, Verification SEM/C/O overlay URLs are cache-busted using `human_roi_saved_at`.
- Verification labels explicitly switch to `Human ROI` when a saved Human ROI exists.
- Saved multi-region Human ROI contours are used for the displayed SEM/C/O overlays.
- Dynamic Human ROI overlay generation can use local original assets even when R2 is not configured (useful for local/dev runs).
- Human ROI editing points were reduced from a 5 px radius to a small 2.2 px marker so residue edges remain visible.
- Existing Human ROI, Ground Truth, C/O recalculation, and multi-region behavior is preserved.
