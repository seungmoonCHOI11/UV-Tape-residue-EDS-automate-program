# V21.2 UI Patch

- Verification is now a fixed two-column inspection layout matching the requested reference: SEM + Full EDS on the upper row, C + O maps on the lower row, and Analysis Result fixed on the right spanning both rows.
- C and O are displayed side-by-side, not stacked on desktop.
- Analysis Result includes score, confidence, component metric bars, C/O ROI-to-global values with multiplicative ratios, ROI area, ROI coverage, mask quality, and connected-region count.
- New analysis/re-analysis SEM overlay no longer draws the yellow Local Ring.
- Decision bands remain Residue >= 70, Ambiguous 60-69, Non-residue < 60.
- Existing stored assets may still show a legacy yellow ring until Re-analysis regenerates them.
