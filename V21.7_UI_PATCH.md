# V21.7 UI PATCH

## Changes
- Enlarged Analysis Result typography for readability.
- Enlarged score, confidence, metric labels, ROI information and decision rule text.
- C ROI / Global and O ROI / Global multiplier values are now color-coded:
  - green: ROI is higher than Global (> 1.0x)
  - red: ROI is lower than Global (< 1.0x)
  - gray: approximately equal to Global
- Existing V21.6 analysis logic and all existing UI/data functionality are preserved.
