# UV-Tape Residue EDS v14.0

## Purpose
This release modifies the actual v13.6 application source. It is not a static HTML prototype.

## Verification viewer
- Page 1 SEM is extracted as the SEM micrograph only.
- Page 1 Full EDS Map is stored separately and displayed without recompositing.
- Page 2 Full Element Maps is stored as the original five-panel element-map region.
- Page 2 SE/C/N/O/Si are cropped independently using the verified 1240 x 1754 Bruker layout:
  - SE: x=100..640, y=190..550
  - C: x=660..1200, y=190..550
  - N: x=100..640, y=570..930
  - O: x=660..1200, y=570..930
  - Si: x=100..640, y=950..1310
- The same normalized ROI generated from the Page-2 SE reference is projected to each individual map.
- Local Ring is generated by dilation around the ROI and shown as a yellow boundary; ROI is shown as a red boundary.
- Raw images and viewer-only overlays are stored separately.
- `object-fit: contain` is used for analytical images to prevent UI clipping.

## Residue decision
The current CV score remains:
- SEM morphology: 45%
- C evidence: 20%
- O evidence: 20%
- C/O spatial overlap: 15%

Binary CV result:
- Score >= 0.50 -> Residue
- Score < 0.50 -> Non-residue

Confidence is reported separately. OpenAI is not the individual-point classifier.

## Dashboard
The dashboard now summarizes the currently loaded project by:
- saved Power / Time conditions
- total / Residue / Non-residue / Review counts
- condition-level result table
- overall distribution
- Zone-level result table
- Power / Time matrix
- representative Residue / Non-residue / Review points

## Existing data
Existing projects created with older extraction assets should be re-analyzed from their R2 source PDFs after deployment so the new exact crops and ROI/Local Ring assets are generated. The existing `Re-analyze` action is retained for this purpose.
