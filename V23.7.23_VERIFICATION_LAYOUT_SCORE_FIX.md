# v23.7.23 Verification Layout + Score Fix

- Verification modal widened to 99vw / max 1500px.
- Point Navigator narrowed to 175px so the central SEM/EDS inspection area gets more width.
- Central SEM and C/O panels enlarged vertically while preserving `object-fit: contain`.
- Point Navigator now uses `human_roi_rule_result` when a Human ROI exists, so a Human ROI Residue is not incorrectly listed as Ambiguous.
- Result filtering uses the same resolved result.
- Human ROI score is recalculated from the displayed limiting C/O ratio in the frontend rather than trusting a stale cached `human_residue_score`.
- Backend Human ROI and automatic score calibration remain aligned: 3x=70, ~5x=81, ~7x=88, ~10x=94, ~15x=99, 20x+=100.
- Classification gates remain unchanged: both C/O >=3x Residue; both >=2x with either <3x Ambiguous; otherwise Non-residue.
