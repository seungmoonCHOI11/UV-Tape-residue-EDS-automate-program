# V13.3 Image Loading Fix

Fixed the backend R2 asset endpoint bug where `r2.configured` (a boolean property) was incorrectly called as `r2.configured()`.

This caused `/api/assets/{point_id}/{asset_type}` to fail when serving R2-backed images, resulting in broken SEM/EDS/element-map images in Image Gallery and Verification.

All occurrences in `backend/app/main.py` were corrected from `r2.configured()` to `r2.configured`.

V13.2 loading/hydration changes are preserved.
