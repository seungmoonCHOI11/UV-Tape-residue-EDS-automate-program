# v23.7.5 — Verification image loading / Human ROI canvas fix

- Verification now prefers already-stored SEM/C/O assets before expensive dynamic overlays when no Human ROI has been saved.
- Human ROI editor always uses the original SEM asset as its canvas background instead of waiting for a generated overlay.
- Human ROI dynamic SEM/C/O overlays are prebuilt immediately after SAVE so the next render does not trigger three independent expensive generations.
- Dynamic Human ROI overlay generation now uses the saved Human ROI polygon mask directly and skips the full residue detector when a Human ROI exists.
- C/O source maps are loaded only for overlay types that need them.
- Existing freehand drawing, smoothing, multi-region ROI, 4 px ROI line, Human ROI C/O rule, and Ground Truth storage are preserved.
