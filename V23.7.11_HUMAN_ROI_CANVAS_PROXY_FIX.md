# V23.7.11 — Human ROI Canvas Image Fix

- Human ROI editor now loads the original SEM through the backend `manual_sem` proxy endpoint.
- R2 presigned URLs are no longer drawn directly into the browser canvas, avoiding cross-origin canvas/taint issues.
- The editor fetches the SEM as a same-origin API response, converts it to a Blob URL, then draws it on the canvas.
- Point navigation still resets the editor to the closed button state.
- Existing freehand drawing, light smoothing, 4 px line width, multiple regions, C/O 3× rule, and Human ROI save flow are preserved.
