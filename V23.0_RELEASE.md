# UV-Tape-residue-EDS v23.0

## v22.0 preserved
- Existing Project loading, Dashboard, Verification, Gallery, AI Analysis, Re-analyze, R2/Supabase integration, uploads and Human Verification are preserved.
- Dual C+O rule remains: automatic Residue requires C ROI/Global >= 1.50x AND O ROI/Global >= 1.50x.
- Local Ring remains excluded from the decision.

## v23.0 changes
- OpenAI ROI assist runs for all newly analyzed/re-analyzed Points by default (`OPENAI_ROI_MODE=all`), but remains non-authoritative for Point classification.
- Verification now supports manual polygon ROI editing directly on the SEM image.
- Human ROI is stored in analysis metadata as Ground Truth candidate data.
- C/O/N/Si are recalculated against the manually selected ROI and the whole valid analytical image.
- Human ROI vs AI ROI IoU is stored when AI boxes are available.
- Dynamic SEM/C/O overlays use the saved Human ROI after manual confirmation.
- Manual ROI data can accumulate across 108+ verified Points for later ROI-engine evaluation/reference; it does not silently retrain the OpenAI base model.
