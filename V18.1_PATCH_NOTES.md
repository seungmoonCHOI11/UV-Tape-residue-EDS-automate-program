# v18.1 Patch Notes

## Critical fix
- Fixed a production crash in `backend/app/point_worker.py` where `ai_boxes` was referenced outside its scope.
- The worker now reads `payload.get("ai_roi_boxes")` for the AI-guided ROI status/count.

## OpenAI environment compatibility
- Existing `OPENAI_API_KEY` is still used.
- Existing `OPENAI_MODEL` is still used for ROI assistance when `OPENAI_ROI_MODEL` is not set.
- No new API key is required.

## Analysis behavior preserved
- OpenAI ROI assistance remains a coarse candidate/guide only.
- OpenCV remains responsible for the actual irregular ROI mask and individual Point classification.
- ROI-vs-global analytical comparison is preserved; the yellow Local Ring is visual-only.
- Existing Dashboard, Verification, Gallery, AI Review, Re-analyze, R2, Supabase and Human Verification flows are preserved.
