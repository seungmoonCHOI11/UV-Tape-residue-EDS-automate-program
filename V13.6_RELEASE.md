# v13.6 — production fix set

1. Removed `next/dynamic(..., { ssr:false })` from `app/page.js`; `AppClient` is imported directly as a Client Component for Next.js 15 compatibility.
2. Verification and Gallery images use ordered asset fallbacks: enhanced/overlay → raw image → no-image state.
3. Score is displayed as `NN / 100` while the stored CV score remains 0–1.
4. Gallery Lightbox now renders every available image even when the enhanced asset is missing.
5. Backend `/api/assets/...` transparently falls back from enhanced overlays to raw assets and uses no-store redirects.
6. Re-analysis uploads the complete asset set to R2 again, including C/N/O/Si raw and overlay images.
7. Re-analysis updates analysis/assets for existing Points without upserting the existing Point row, so Human verification and existing AI metadata are preserved.
8. New analysis uses the same worker asset set.
9. Project loading uses bounded bulk Supabase queries instead of one analysis/assets query per Point, reducing initial load latency for 108–900 Point datasets.
10. Initial loading retries Render cold-start failures before showing an error.
11. SEM/EDS crop windows were widened to retain SEM metadata and EDS right-edge content.

Existing Point rows are not deleted by v13.6.
