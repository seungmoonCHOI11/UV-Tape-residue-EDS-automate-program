# V23.7.15 — Human ROI overlay speed optimization

## Base
- V23.7.14 remains the functional baseline.
- Human ROI drawing / smoothing / save behavior is unchanged.

## Change
After saving Human ROI, Verification SEM/C/O overlays no longer rerun the full residue feature pipeline for each image request.

For saved Human ROI points:
- SEM overlay loads only the original SEM + saved Human ROI mask.
- C overlay loads only the original SEM + C map + saved Human ROI mask.
- O overlay loads only the original SEM + O map + saved Human ROI mask.
- N/Si maps are no longer loaded for these display-only overlay requests.
- Existing legacy/AI-CV points retain the previous calculation path.
- Corrupt/empty cached raw images are automatically redownloaded.

## Expected effect
The Human ROI Save operation still performs the required C/O recalculation and Ground Truth persistence, but the subsequent SEM/C/O display refresh should be substantially faster because each overlay no longer repeats the full C/O/N/Si feature calculation.
