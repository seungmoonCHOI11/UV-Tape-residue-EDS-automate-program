# v23.7.3 — Human ROI drawing performance + algorithmic smoothing

- Human ROI drawing no longer stores every pointermove sample in React state.
- Pointer movement is rendered directly to canvas to reduce lag.
- Dense/repeated mouse samples are removed before ROI completion.
- A conservative one-pass closed moving-average smoothing is applied when an ROI region is completed or saved.
- Smoothing is intended only to suppress hand jitter and small drawing noise; it does not use AI or infer residue boundaries.
- The raw active stroke is not altered while drawing; smoothing occurs only at region completion/save.
- Existing Human ROI multi-region behavior, C/O calculation, Ground Truth storage, and 3x C/O rule are preserved.
