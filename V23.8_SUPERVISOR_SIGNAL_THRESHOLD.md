# V23.8 — Supervisor Request: C/O/N Signal Summary + Adaptive Threshold Visibility

## Added
- Dashboard `C / O / N Signal Summary` grouped by Power / Time.
- Counts per condition for C, O, N signal ratio >= 1.50x.
- Counts where all three C/O/N are >= 1.50x.
- Counts where all three C/O/N are >= 3.00x.
- N remains a diagnostic signal and is not added to the residue decision rule.
- Verification now shows the adaptive threshold mode and local-background/MAD parameters when available.
- Existing C/O residue rule remains: both C and O >= 3.00x => Residue; both >=1.50x but either <3.00x => Ambiguous; otherwise Non-residue.

## Threshold approach
The SEM detector uses local-background subtraction and a robust MAD-derived threshold rather than one fixed global grayscale threshold. Bright and dark contrast branches are both considered. OpenAI ROI assistance remains a second-stage visual aid for uncertain cases; it does not directly make the final Point residue decision.

## Why the C/O/N summary uses 1.50x and 3.00x
- 1.50x is shown as a `signal present / clearly elevated` diagnostic threshold.
- 3.00x is shown as a `strong signal` threshold and remains the C/O residue gate.
- N is intentionally diagnostic only until a separate N-based residue rule is established.
