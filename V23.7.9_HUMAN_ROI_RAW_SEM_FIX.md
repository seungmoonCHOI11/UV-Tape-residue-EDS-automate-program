# v23.7.9 — Human ROI raw SEM loading fix

- Fixed the Human ROI editor getting stuck at `SEM 이미지를 불러오는 중...`.
- v23.7.8 attempted to request `dynamicAsset(p,"sem")`, but the backend dynamic renderer only generates overlay asset types and therefore cannot reliably serve a raw `sem` dynamic asset for legacy points.
- Added a dedicated `/api/assets/{point_id}/manual_sem` compatibility route that resolves the original `sem` asset first and falls back to legacy SEM overlay only when necessary.
- Human ROI editor now requests the dedicated raw-SEM endpoint instead of the unsupported dynamic `sem` endpoint.
- Existing Verification images, Human ROI freehand drawing, smoothing, multi-region support, Human ROI save, C/O recalculation, and 3× rule are unchanged.
