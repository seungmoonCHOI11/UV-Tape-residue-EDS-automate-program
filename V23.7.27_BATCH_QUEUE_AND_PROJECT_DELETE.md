# V23.7.27 — Batch Analysis Queue + Project Delete

- Multiple upload jobs are placed into a server-side FIFO analysis queue.
- One analysis job is processed at a time to reduce Render memory pressure.
- Upload returns after queue registration; the browser no longer waits for the full 108-point analysis.
- New Analysis shows queue status/progress for submitted jobs.
- Existing project history remains intact when new PDFs are uploaded.
- Added project deletion endpoint and UI confirmation.
- Project deletion removes project Points, analysis results, review history, point assets, local project files, and R2 objects under the project prefix.
- Running/queued jobs are marked cancelled when their project is deleted.
- Existing Human ROI, substrate mapping, Verification filters, and score rules are preserved.
