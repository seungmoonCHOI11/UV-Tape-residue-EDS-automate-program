# v23.6 C/O 3× Dual-Gate Rule

- Final residue classification now requires **both C and O ROI/Global ratios >= 3.00×**.
- If both C and O are >= 1.50× but either is below 3.00×, the result is **Ambiguous**.
- If either C or O is below 1.50×, the result is **Non-residue**.
- Score is derived from the limiting C/O ratio (`min(C ratio, O ratio)`):
  - <1.50× → 0–59
  - 1.50–<3.00× → 60–69
  - >=3.00× → 70–100 (reaching 100 at 5.00× or above)
- SEM Morphology and Spatial Overlap remain diagnostic metrics only and cannot override the C/O rule.
- The same rule is used for automatic AI/CV ROI analysis and saved Human ROI re-analysis.
