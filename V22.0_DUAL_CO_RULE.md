# V22.0 — Dual C/O Residue Rule

## Why
Verification showed cases where a visually obvious SEM object received a high score even though only one EDS channel was elevated, e.g. C 1.09x / O 2.00x. Another case had C 1.77x / O 0.75x. These are not sufficient for the lab residue definition.

## New Point-level rule
A Point can be automatically classified as **Residue** only when:

- C ROI / Global >= **1.50x**
- O ROI / Global >= **1.50x**
- ROI quality and SEM physical evidence are also sufficient

If either channel is below 1.50x, the automatic score cannot enter the Residue band.

- < 1.20x: background-like
- 1.20–1.49x: moderate evidence
- >= 1.50x: strong evidence

This is intentionally stricter than using a weighted average of C and O. One strong channel cannot compensate for one background-like channel.

## ROI changes
- The bottom metadata/scale-bar strip remains excluded.
- ROI expansion is reduced from 18% to 10% around the detected candidate.
- Fragmented masks are coherence-filtered so scattered SEM grain/shadow pixels do not become one giant ROI.
- Local Ring is not used as a baseline.

## Verification UI
- ANALYSIS RESULT heading and score are larger.
- C/O ROI/Global multipliers: green >= 1.50x, red <= 0.90x, neutral otherwise.
- A note directly states the C+O simultaneous-increase rule.

## Existing functionality
This version is a patch of v21.8. Existing Project loading, Dashboard, Verification, Gallery, AI Analysis, Re-analyze, R2/Supabase integration, uploads, and Human Verification handling are retained.
